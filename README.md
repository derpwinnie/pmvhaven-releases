# PMVHaven native clients — releases

Download page for the native PMVHaven apps (Android, macOS, Linux). The apps also check this
repository for updates. Unofficial, not affiliated with PMVHaven. Adults only.

Pick the newest entry under [Releases](../../releases): the APK for Android, the zip for macOS
(Apple silicon) or the tar.gz for Linux. `SHA256SUMS.txt` lists the checksums.
